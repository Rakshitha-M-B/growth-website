# Growth Website 🌱

A modern and responsive business landing page built using **HTML5**, **CSS3**, and **JavaScript**. This project showcases a clean user interface, responsive layouts, and interactive components, making it suitable as a frontend portfolio project.

## 📸 Preview

![Growth Website Homepage](screen.png)

---

## 🚀 Features

- Responsive Navigation Bar
- Modern Hero Section
- Video Preview Section
- Customer Testimonials
- Pricing Plans
- Interactive FAQ Accordion
- Responsive Design
- Clean UI with Google Fonts
- Font Awesome Icons
- Organized and Maintainable Code

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Google Fonts
- Font Awesome

## 💻 Getting Started

Clone the repository:

```bash
git clone https://github.com/Rakshitha-M-B/growth-website.git
```

Navigate to the project folder:

```bash
cd growth-website
```

Open `index.html` in your browser or use the **Live Server** extension in VS Code.
